# 🚀 Smart Complaint Management System

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) based web application designed to streamline and automate the process of handling user complaints in an organization.

---

## 📌 Overview

The Smart Complaint Management System provides a centralized platform where users can register complaints and track their status, while administrators can manage, update, and resolve them efficiently. The system improves transparency, reduces delays, and ensures better communication.

---

## ⚙️ Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **API:** RESTful APIs  

---

## ✨ Features

- User Registration and Login  
- Complaint Submission  
- View and Track Complaint Status  
- Admin Panel for Managing Complaints  
- Status Updates (Pending → In Progress → Resolved)  
- Secure Data Storage
